# Superseded: the lattice-diffusion experiments

Everything in this directory is the route that preceded `code/slicefill/`: SDEdit on single planes,
write-back into the voxel field, a 3-D SinDiffusion trained on crops of the fitted latent volume,
and the aggregation rules that followed. It is kept because the page's route section refers to
these results and because several of them are negative results worth having on record.

The method the paper reports is `code/slicefill/`, and none of these scripts are on its path.
